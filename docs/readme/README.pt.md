## O que é o Rawya?

Rawya é um reprodutor nativo para macOS feito para quem assiste a vídeos em diferentes idiomas. Ele gera legendas a partir da fala e as traduz para o idioma que você lê.

## Destaques

- Geração e tradução automática de legendas em vários idiomas
- Exibição das legendas prontas enquanto o restante ainda é processado
- Processamento local com a IA da Apple em Macs compatíveis
- Reprodução de formatos comuns de vídeo e áudio
- Legendas, playlists, capítulos, picture-in-picture e histórico
- Controles de vídeo, áudio, legendas, teclado, mouse, trackpad e gestos

## Requisitos

- Legendas com IA local da Apple: macOS 26 ou posterior
- Reprodução básica em Apple Silicon: macOS 12 ou posterior
- Reprodução básica em Intel Mac: macOS 10.15 ou posterior

## Baixar

Baixe o DMG mais recente em [GitHub Releases](https://github.com/rawya-ai-player/client-macos/releases/latest) e arraste o Rawya para Aplicativos. Versões estáveis são assinadas com Developer ID e notarizadas pela Apple.

## Atualizações

O Rawya verifica automaticamente as atualizações estáveis uma vez por dia. Você também pode escolher **Verificar atualizações…** no menu do aplicativo a qualquer momento. Ative **Baixar e instalar atualizações automaticamente** em **Ajustes > Geral** para baixar atualizações verificadas em segundo plano e instalá-las ao encerrar o Rawya.

As atualizações automáticas e os downloads manuais usam a mesma versão estável do GitHub Release. O GitHub também fornece os arquivos de código-fonte de cada versão estável.

## Compilar localmente

Instale o Xcode mais recente, execute `./other/download_libs.sh` e abra o `.xcodeproj` no Xcode para compilar o Scheme principal.
