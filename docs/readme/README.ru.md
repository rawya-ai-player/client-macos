## Что такое Rawya?

Rawya — нативный плеер для macOS для тех, кто смотрит видео на разных языках. Он создаёт субтитры из речи и переводит их на язык, который вы читаете.

## Возможности

- Автоматическое создание и перевод субтитров на разных языках
- Показ готовых субтитров до завершения обработки всего видео
- Локальная обработка аудио с ИИ Apple на поддерживаемых Mac
- Воспроизведение распространённых видео- и аудиоформатов
- Субтитры, плейлисты, главы, режим «картинка в картинке» и история
- Настройка видео, аудио, субтитров, клавиатуры, мыши, трекпада и жестов

## Требования

- Локальные субтитры Apple AI: macOS 26 или новее
- Базовое воспроизведение на Apple Silicon: macOS 12 или новее
- Базовое воспроизведение на Intel Mac: macOS 10.15 или новее

## Скачать

Загрузите последний DMG из [GitHub Releases](https://github.com/rawya-ai-player/client-macos/releases/latest) и перенесите Rawya в «Программы». Стабильные сборки подписаны Developer ID и нотариально заверены Apple.

## Обновления

Rawya автоматически проверяет наличие стабильных обновлений один раз в день. Вы также можете в любое время выбрать **Проверить обновления…** в меню приложения. Включите **Автоматически загружать и устанавливать обновления** в разделе **Настройки > Основные**, чтобы проверенные обновления загружались в фоновом режиме и устанавливались при выходе из Rawya.

Автоматические обновления и ручные загрузки используют один и тот же стабильный выпуск GitHub Release. GitHub также предоставляет архивы исходного кода для каждой стабильной версии.

## Локальная сборка

Установите последнюю версию Xcode, запустите `./other/download_libs.sh`, откройте `.xcodeproj` в Xcode и соберите основную схему приложения.
