# Rawya 1.0.1

## 简体中文

- 使用 Xcode 27 和 macOS 27 SDK 构建；基础播放需要 macOS 12 或更高版本，Apple 本地 AI 字幕需要 macOS 26 或更高版本。

- 修复取消 AI 字幕语言确认后，开关快捷设置或切换标签会再次弹出确认窗口的问题。同一次播放中取消后不再自动弹出，重新打开视频后按设置重新判断。
- 字幕生成方式简化为“自动生成”和“手动生成”。自动模式使用默认语言直接生成；手动模式在打开视频时显示语言确认窗口，确认后开始生成。
- 两种方式下均提供“仅在没有字幕时生成”勾选框，默认勾选，并保留旧版“始终自动生成”的设置。已有字幕时跳过自动生成及语言确认。
- 因已有字幕而跳过时，在视频开始播放后于右上角短暂显示提示：“当前视频已有字幕，不会自动生成 AI 字幕”。

## English

- Built with Xcode 27 and the macOS 27 SDK. Basic playback requires macOS 12 or later; Apple Local AI subtitles require macOS 26 or later.

- Fixed the AI subtitle language prompt reappearing after cancellation when opening or closing quick settings or switching tabs. Cancellation lasts until the video is opened again.
- Simplified generation to Automatic and Manual. Automatic uses the saved languages; Manual asks you to confirm the audio language when a video opens.
- Added a shared “Generate only when subtitles are missing” checkbox under both modes, enabled by default while preserving the previous always-generate preference. Existing subtitles suppress automatic generation and the language prompt.
- Added a brief notice in the upper-right corner at playback start when existing subtitles cause AI generation to be skipped.
