# Rawya 1.0.0

Rawya 的首个正式公开版本，为 macOS 提供简洁、现代的本地音视频播放体验。

## 主要内容

- 支持常见视频和音频格式、字幕、播放列表与章节。
- 支持画中画、音乐模式、播放历史和视频缩略图。
- 提供音频、视频、字幕及键盘、鼠标、触控板操作设置。
- 支持稳定通道的每日自动检查和菜单手动检查更新。
- 可在通用设置中启用自动下载，并在退出 Rawya 时安装已验证更新。

## 安装

下载 DMG，打开后将 Rawya 拖入“应用程序”文件夹。本版本使用 Developer ID 签名并经过 Apple 公证。

- Intel Mac：macOS 10.15 或更高版本。
- Apple 芯片 Mac：macOS 12 或更高版本。

本 Release 同时提供 Sparkle 更新 ZIP、签名 appcast、SHA-256 校验文件和对应源码归档。
