# Rawya 1.0.0

**看外语视频，不再被字幕限制。**

Rawya（若雅）是一款免费、开源的 macOS 播放器。打开本地视频后，它可以从语音自动生成字幕，并翻译成你熟悉的语言；字幕会边生成边显示，不必等待整部视频处理完成。

[**下载 Rawya 1.0.0 for macOS（DMG）**](https://github.com/rawya-ai-player/client-macos/releases/download/rawya-v1.0.0/Rawya-1.0.0-1005.dmg)

> 普通用户只需下载上面的 DMG。安装包已使用 Developer ID 签名并经过 Apple 公证。

## AI 字幕

- **自动生成字幕：** 没有字幕的视频，也能从语音生成可阅读的字幕。
- **自动翻译字幕：** 将生成的字幕翻译成你熟悉的语言。
- **边生成边观看：** 已完成的字幕会立即显示，无需等待整部视频处理完。
- **本地处理：** 在支持的 Mac 上使用 Apple 本地 AI，音频不离开设备。

## 播放体验

- 播放常见视频和音频格式。
- 管理外挂字幕、播放列表、章节和播放历史。
- 支持画中画、音乐模式和视频缩略图。
- 可调整视频、音频、字幕以及键盘、鼠标和触控板操作。

## 系统要求

- AI 字幕：macOS 26 或更高版本，具体可用语言取决于系统支持。
- Apple 芯片 Mac 基础播放：macOS 12 或更高版本。
- Intel Mac 基础播放：macOS 10.15 或更高版本。

## 安装

下载并打开 DMG，将 Rawya 拖入“应用程序”文件夹，然后从“应用程序”中打开。

## 后续更新

Rawya 每天自动检查一次稳定版更新，也可以随时从应用菜单选择“检查更新…”。在“设置 > 通用”中启用自动下载后，新版本会在后台下载，并在退出 Rawya 时安装。

本项目采用 GPLv3 许可证，源码由 GitHub 随本版本自动提供。Release 中的 ZIP 和 appcast 仅供应用内自动更新使用，无需手动下载。
